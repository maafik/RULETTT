# 🔄 Синхронизация веб-приложения с Android

## ⚠️ Важно: Автоматической синхронизации НЕТ!

**Capacitor НЕ синхронизирует изменения автоматически!**

После каждого изменения в веб-коде нужно **вручную синхронизировать** с Android проектом.

## 🔄 Как работает синхронизация

### Процесс работы:

```
1. Вы меняете веб-код (React компоненты, стили, логику)
   ↓
2. Собираете веб-приложение (npm run build)
   ↓
3. Синхронизируете с Android (npm run cap:sync)
   ↓
4. Открываете Android Studio и видите обновления
   ↓
5. Собираете APK/AAB в Android Studio
```

## 📋 Пошаговая инструкция

### Шаг 1: Измените веб-код

Редактируйте файлы в папке `src/`:
- `src/components/` - компоненты
- `src/pages/` - страницы
- `src/lib/` - утилиты
- `src/App.tsx` - главный компонент
- И т.д.

### Шаг 2: Соберите веб-приложение

```bash
npm run build
```

Это создаст папку `dist/` с собранными файлами.

### Шаг 3: Синхронизируйте с Android

```bash
npm run cap:sync
```

**Что делает эта команда:**
- ✅ Собирает веб-приложение (`npm run build`)
- ✅ Копирует файлы из `dist/` в `android/app/src/main/assets/public/`
- ✅ Обновляет конфигурацию Capacitor
- ✅ Обновляет зависимости (если нужно)

### Шаг 4: Откройте Android Studio

```bash
npm run cap:open:android
```

Или откройте вручную папку `android/` в Android Studio.

### Шаг 5: Соберите APK/AAB

В Android Studio:
- **Build → Build Bundle(s) / APK(s) → Build APK(s)** (для тестирования)
- **Build → Generate Signed Bundle / APK** (для публикации)

## 🚀 Быстрая команда (всё в одном)

Вместо шагов 2-3, можно использовать одну команду:

```bash
npm run cap:sync
```

Эта команда автоматически:
1. Соберет веб-приложение (`npm run build`)
2. Синхронизирует с Android (`npx cap sync`)

## 📝 Что синхронизируется

### ✅ Синхронизируется автоматически:

- **Веб-код** (HTML, CSS, JavaScript из `dist/`)
- **Конфигурация Capacitor** (`capacitor.config.json`)
- **Плагины Capacitor** (если добавили новые)
- **Иконки и splash screen** (если изменили)

### ❌ НЕ синхронизируется автоматически:

- **Нативные настройки Android** (`build.gradle`, `AndroidManifest.xml`)
- **Java/Kotlin код** (если есть кастомный нативный код)
- **Ресурсы Android** (иконки, строки в `res/`)
- **Зависимости** (нужно синхронизировать вручную через `cap:sync`)

## 🔧 Полезные команды

### Полная синхронизация (рекомендуется):
```bash
npm run cap:sync
```
Собирает веб-приложение и синхронизирует всё.

### Только копирование (без сборки):
```bash
npm run cap:copy
```
Копирует уже собранные файлы из `dist/` (быстрее, если уже собрали).

### Открыть Android Studio:
```bash
npm run cap:open:android
```

### Проверить конфигурацию:
```bash
npx cap doctor
```
Покажет, всё ли настроено правильно.

## 🔍 Проверка синхронизации

### Где находятся файлы в Android проекте:

После синхронизации веб-файлы находятся здесь:
```
android/app/src/main/assets/public/
```

Там должны быть:
- `index.html`
- `assets/` (CSS, JS файлы)
- Другие файлы из `dist/`

### Как проверить, что синхронизация прошла:

1. **Проверьте папку:**
   ```
   android/app/src/main/assets/public/
   ```
   Должны быть файлы из `dist/`

2. **Проверьте дату изменения файлов:**
   Файлы должны иметь текущую дату/время

3. **В Android Studio:**
   - Откройте проект
   - Проверьте, что файлы в `assets/public/` обновились

## ⚠️ Частые ошибки

### Ошибка: "Файлы не обновились"

**Решение:**
1. Убедитесь, что выполнили `npm run build` перед `cap:sync`
2. Проверьте, что папка `dist/` существует и содержит файлы
3. Попробуйте удалить `android/app/src/main/assets/public/` и синхронизировать снова

### Ошибка: "Изменения не видны в приложении"

**Решение:**
1. Убедитесь, что синхронизировали (`npm run cap:sync`)
2. Пересоберите APK в Android Studio
3. Переустановите приложение на устройстве

### Ошибка: "Конфигурация не обновилась"

**Решение:**
1. Проверьте `capacitor.config.json`
2. Выполните `npm run cap:sync` снова
3. Перезапустите Android Studio
