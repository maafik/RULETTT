# ✅ Проверка получателя уведомлений

## 📊 Текущий статус (отправитель)

По вашим логам, на аккаунте отправителя все настроено:
- ✅ Поддержка FCM: Да
- ✅ Messaging инициализирован: Да
- ✅ Разрешение: granted
- ✅ VAPID ключ: Найден
- ✅ Service Worker: Зарегистрирован
- ✅ Токен получен: Да
- 📱 Токен: `dwuApPfbdH7h23rpH-u9mS:APA91bF...`

## 🔍 Что проверить для получателя

### 1. Проверьте токен получателя в Firestore

**В Firebase Console:**
1. Firestore Database → Коллекция `userFCMTokens`
2. Найдите документ с UID получателя (второго аккаунта)
3. Проверьте, что поле `token` заполнено

**Если токена нет:**
- Получатель должен:
  1. Авторизоваться в приложении
  2. Разрешить уведомления (должно появиться окно запроса)
  3. Дождаться сохранения токена

**Как узнать UID получателя:**
- Firebase Console → Authentication → Users
- Или в консоли браузера получателя: `auth.currentUser.uid`

### 2. Проверьте диагностику на аккаунте получателя

**На аккаунте получателя (второй браузер/вкладка):**
1. Откройте приложение
2. Авторизуйтесь
3. Откройте консоль браузера (F12)
4. Должны быть логи:
   ```
   🚀 Инициализация системы уведомлений...
   ✅ Токен уведомлений получен: ...
   ✅ FCM токен обновлен для пользователя: ...
   ```

**Если токен не получен:**
- Проверьте, разрешены ли уведомления
- Проверьте, что Service Worker зарегистрирован
- Проверьте консоль на ошибки

### 3. Проверьте создание уведомлений

**При создании/изменении заказа:**
1. В консоли браузера отправителя должны быть логи:
   ```
   📤 Создаем уведомление в Firestore...
   ✅ Уведомление создано в Firestore для пользователя: ...
   ✅ Токен получателя найден: ... (или ⚠️ Токен получателя НЕ найден)
   ```

2. В Firebase Console → Firestore → `notifications`:
   - Должен появиться новый документ
   - Проверьте поле `targetUserUid` — должно совпадать с UID получателя

### 4. Проверьте Cloud Functions

**В Firebase Console:**
1. Functions → должна быть функция `sendNotification`
2. Статус должен быть "Развернута"

**Если функции нет:**
```bash
cd functions
npm install
firebase deploy --only functions
```

**Проверьте логи:**
1. Functions → Logs
2. Найдите функцию `sendNotification`
3. При создании уведомления должны быть логи:
   - `📬 Новое уведомление создано: ...`
   - `✅ Токен найден для пользователя: ...` (или `⚠️ Токен не найден`)
   - `✅ Уведомление успешно отправлено: ...` (или ошибка)

### 5. Проверьте правильность targetUserUid

**Проблема может быть в том, что:**
- `targetUserUid` в уведомлении не совпадает с UID получателя
- Функция `getMusicianUidByName()` возвращает неправильный UID

**Проверка:**
1. В консоли браузера отправителя при создании заказа:
   - Должен быть лог: `📤 Создаем уведомление в Firestore...`
   - Должен быть лог: `   Получатель: UID_ПОЛУЧАТЕЛЯ`
   - Сравните этот UID с UID получателя в Authentication

2. В Firestore → `notifications`:
   - Проверьте поле `targetUserUid` в созданном уведомлении
   - Должно совпадать с UID получателя

## 🧪 Тестирование

**В Firebase Console:**
1. Firestore Database → `notifications` → новый документ
2. Заполните:
   ```json
   {
     "targetUserUid": "UID_ПОЛУЧАТЕЛЯ",
     "orderId": "test",
     "title": "Тест",
     "body": "Тестовое уведомление",
     "status": "test",
     "read": false,
     "createdAt": "Timestamp.now()"
   }
   ```
3. Cloud Function должна автоматически отправить уведомление
4. Проверьте логи Cloud Functions
5. У получателя должно появиться уведомление

### Тест 2: Проверьте токен получателя

**В Firebase Console:**
1. Firestore Database → `userFCMTokens`
2. Найдите документ с UID получателя
3. Проверьте поле `token` — должно быть заполнено

**Если токена нет:**
- Получатель должен авторизоваться и разрешить уведомления
- Перезагрузить страницу
- Проверить консоль на ошибки

**Решение:**
1. Получатель должен авторизоваться
2. Разрешить уведомления
3. Дождаться сохранения токена
4. Проверить в Firestore → `userFCMTokens`

### Проблема: Cloud Functions не развернуты

**Решение:**
```bash
cd functions
npm install
firebase deploy --only functions
```

### Проблема: Неправильный targetUserUid

**Решение:**
1. Проверьте функцию `getMusicianUidByName()`
2. Проверьте, что UID получателя правильный
3. Сравните UID в уведомлении с UID в `userFCMTokens`
