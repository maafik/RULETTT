# 📬 Уведомления БЕЗ Cloud Functions

## ⚠️ Ограничение

Без Cloud Functions уведомления работают **только когда приложение открыто** у получателя.

## ✅ Что работает

### 1. Уведомления когда приложение открыто

**Как это работает:**
1. Отправитель создает уведомление в Firestore
2. Приложение получателя подписано на изменения в Firestore
3. Когда создается новое уведомление, получатель видит его сразу
4. Показывается браузерное уведомление

**Преимущества:**
- ✅ Работает бесплатно
- ✅ Не нужен сервер
- ✅ Мгновенные уведомления
- ✅ Работает в реальном времени

**Недостатки:**
- ❌ Не работает, когда приложение закрыто
- ❌ Не работает, когда вкладка неактивна
- ❌ Не работает на мобильных устройствах в фоне

## 🔧 Текущая реализация

### Слушатель Firestore

Приложение получателя подписывается на уведомления через Firestore real-time listener:

```typescript
// Слушаем уведомления для текущего пользователя
const q = query(
  notificationsRef,
  where("targetUserUid", "==", currentUserUid),
  orderBy("createdAt", "desc"),
  limit(1)
);

onSnapshot(q, (snapshot) => {
  // Показываем уведомление
});
```

### Когда это работает

- ✅ Приложение получателя открыто
- ✅ Вкладка активна
- ✅ Пользователь авторизован
- ✅ Разрешены уведомления в браузере

## 🚀 Альтернативные решения для фоновых уведомлений

### Вариант 1: Бесплатный сервер (Vercel/Netlify)

**Vercel Serverless Functions:**
```javascript
// api/send-notification.js
export default async function handler(req, res) {
  const { targetUserUid, title, body } = req.body;
  
  // Получаем токен из Firestore
  const token = await getTokenFromFirestore(targetUserUid);
  
  // Отправляем через FCM REST API
  await fetch('https://fcm.googleapis.com/fcm/send', {
    method: 'POST',
    headers: {
      'Authorization': `key=${FCM_SERVER_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      to: token,
      notification: { title, body }
    })
  });
}
```

**Плюсы:**
- ✅ Бесплатно (до лимитов)
- ✅ Просто настроить
- ✅ Работает в фоне

**Минусы:**
- ❌ Нужен FCM Server Key (небезопасно хранить на клиенте)
- ❌ Нужен отдельный сервер

### Вариант 2: Firebase Cloud Functions (платно)

**Плюсы:**
- ✅ Официальное решение
- ✅ Надежно
- ✅ Интеграция с Firebase

**Минусы:**
- ❌ Платно (но есть бесплатный тариф)
- ❌ Нужна настройка

### Вариант 3: Собственный сервер

**Плюсы:**
- ✅ Полный контроль
- ✅ Можно использовать бесплатный хостинг

**Минусы:**
- ❌ Нужно поддерживать сервер
- ❌ Нужен FCM Server Key
