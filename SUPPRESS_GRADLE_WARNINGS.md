# 🔇 Подавление предупреждений Gradle

## ⚠️ Предупреждение об экспериментальной опции

Если вы видите предупреждение:
```
The option setting 'android.overridePathCheck=true' is experimental.
```

## ✅ Решение

### Вариант 1: Подавить все предупреждения (уже применено)

В `android/gradle.properties` добавлено:
```properties
org.gradle.warning.mode=none
```

Это скроет все предупреждения Gradle, включая предупреждение об экспериментальной опции.

### Вариант 2: Подавить только предупреждения (рекомендуется)

Если хотите видеть ошибки, но скрыть предупреждения, используйте:
```properties
org.gradle.warning.mode=summary
```

Это покажет только краткое резюме предупреждений.

### Вариант 3: Оставить как есть

Предупреждение об экспериментальной опции **безопасно игнорировать**:
- Опция работает стабильно
- Она необходима для путей с кириллицей
- Это не ошибка, а просто информационное сообщение

## 📋 Режимы предупреждений Gradle

- `none` - скрыть все предупреждения
- `summary` - показать только краткое резюме
- `all` - показать все предупреждения (по умолчанию)

## 🔍 Где настраивается

Файл: `android/gradle.properties`

Текущая настройка:
```properties
org.gradle.warning.mode=none
```

## ⚠️ Важно

- `org.gradle.warning.mode=none` скроет **все** предупреждения, включая важные
- Если хотите видеть важные предупреждения, используйте `summary`
- Или просто игнорируйте предупреждение об `overridePathCheck` - оно не критично

## 🎯 Рекомендация

Для разработки лучше использовать:
```properties
org.gradle.warning.mode=summary
```

Это покажет важные предупреждения, но скроет избыточные информационные сообщения.

## 📱 После изменения настроек

1. **В Android Studio:**
   - File → Sync Project with Gradle Files
   - Build → Clean Project
   - Build → Make Project (или просто нажмите Ctrl+F9)

2. **Или через меню:**
   - Build → Clean Project
   - Build → Make Project

Примечание: В некоторых версиях Android Studio пункт "Rebuild Project" может называться "Make Project" или находиться в другом месте меню.
