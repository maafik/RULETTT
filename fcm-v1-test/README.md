# 🚀 Автоматическая отправка push-уведомлений через FCM v1

## ✅ Что настроено

1. **Автоматический скрипт** (`auto-send-fcm.js`) - слушает Firestore и отправляет push при создании уведомлений
2. **Ручной скрипт** (`send-fcm.js`) - для тестирования отправки на конкретный токен
3. **Service Account** - настроен для доступа к FCM v1 API

## 🎯 Как использовать

### Вариант 1: Автоматическая отправка (рекомендуется)

**Запустите скрипт, который будет работать постоянно:**

```bash
cd fcm-v1-test
node auto-send-fcm.js
```

**Что делает:**
- ✅ Слушает коллекцию `notifications` в Firestore
- ✅ При создании нового уведомления автоматически:
  1. Получает FCM токен получателя из `userFCMTokens`
  2. Отправляет push через FCM v1 API
  3. Помечает уведомление как отправленное

**Остановка:** `Ctrl+C`

### Вариант 2: Ручная отправка (для тестирования)

**Отправка на конкретный токен:**

```bash
cd fcm-v1-test
node send-fcm.js
```

**Токен в коде:** `JFiWds7FPDZEh5n0h5H235re0vu1`

## 📋 Требования

1. **Node.js** установлен
2. **Зависимости установлены:**
   ```bash
   npm install google-auth-library node-fetch@2 firebase-admin
   ```
3. **Service Account файл** на месте: `frebaze-94560-7912c6031120.json`

## 🔍 Как найти FCM токен получателя

### Способ 1: Firebase Console
1. Firestore Database → Коллекция `userFCMTokens`
2. Найдите документ с UID получателя
3. Скопируйте значение поля `token`

### Способ 2: В консоли браузера получателя
```javascript
const { getUserFCMToken } = await import('@/lib/notifications');
const { auth } = await import('@/lib/firebase');
const token = await getUserFCMToken(auth.currentUser.uid);
console.log('FCM Token:', token);
```

## 🚀 Запуск автоматической отправки

### Шаг 1: Установите зависимости (если еще не установлены)

```bash
npm install firebase-admin
```

### Шаг 2: Запустите автоматический скрипт

```bash
node auto-send-fcm.js
```

### Шаг 3: Проверьте работу

1. Создайте/измените заказ в приложении
2. В консоли скрипта должны появиться логи:
   ```
   📬 Новое уведомление: ...
   ✅ Токен найден: ...
   ✅ Push отправлен успешно!
   ```
3. У получателя должно появиться push-уведомление

## ⚙️ Как это работает

```
1. Приложение создает уведомление в Firestore
   ↓
2. auto-send-fcm.js слушает изменения
   ↓
3. Получает FCM токен получателя из userFCMTokens
   ↓
4. Отправляет push через FCM v1 API
   ↓
5. Помечает уведомление как отправленное (sent: true)
```

## 📝 Логи

Скрипт выводит подробные логи:
- ✅ Успешная отправка
- ⚠️ Предупреждения (токен не найден и т.д.)
- ❌ Ошибки

## 🐛 Решение проблем

### Ошибка: "Token not found"
- Проверьте, что токен получателя сохранен в Firestore
- Проверьте UID получателя

### Ошибка: "Invalid token"
- Токен истек или невалидный
- Получатель должен перезагрузить страницу и разрешить уведомления

### Ошибка: "Service account not found"
- Проверьте, что файл `frebaze-94560-7912c6031120.json` существует
- Проверьте путь к файлу
