# Проверка работы уведомлений

## Диагностика проблемы "не приходят уведомления"

### Шаг 1: Проверьте консоль браузера

Откройте DevTools (F12) → Console и проверьте:

1. **При входе в систему:**
   - ✅ `✅ Firebase Cloud Messaging инициализирован`
   - ✅ `✅ Service Worker зарегистрирован`
   - ✅ `✅ Токен уведомлений получен: ...`
   - ✅ `✅ FCM токен сохранен для пользователя: ...`

2. **При создании/изменении заказа:**
   - ✅ `📤 Создаем уведомление в Firestore...`
   - ✅ `✅ Уведомление создано в Firestore для пользователя ...`

### Шаг 2: Проверьте Firestore

1. Откройте Firebase Console → Firestore Database
2. Проверьте коллекцию `notifications`:
   - Должны появляться новые записи при изменении статуса заказа
   - Проверьте поле `targetUserUid` - это UID получателя
   - Проверьте поле `orderId` - это ID заказа

3. Проверьте коллекцию `userFCMTokens`:
   - Должны быть записи для всех пользователей, которые разрешили уведомления
   - Проверьте поле `token` - это FCM токен

### Шаг 3: Проверьте Cloud Functions

**Важно:** Без Cloud Functions push-уведомления НЕ будут отправляться!

1. Откройте Firebase Console → Functions
2. Проверьте, развернута ли функция `sendNotification`
3. Если нет - следуйте инструкциям в `DEPLOY_FUNCTIONS.md`

### Шаг 4: Проверьте логи Cloud Functions

```bash
firebase functions:log
```

Или в Firebase Console → Functions → Logs

Должны быть сообщения:
- `📬 Новое уведомление создано: ...`
- `✅ Токен найден для пользователя: ...`
- `✅ Уведомление успешно отправлено: ...`

### Шаг 5: Проверьте разрешения браузера

1. В Chrome: Настройки → Конфиденциальность → Уведомления
2. Убедитесь, что для вашего сайта разрешены уведомления
3. Если запрещено - разрешите вручную

## Текущее состояние системы

### ✅ Что работает:

1. **Создание уведомлений в Firestore** - работает
2. **Сохранение FCM токенов** - работает (после обновления правил)
3. **Получение разрешения на уведомления** - работает
4. **Регистрация Service Worker** - работает

### ❌ Что НЕ работает без Cloud Functions:

1. **Отправка push-уведомлений** - нужна Cloud Function
2. **Уведомления когда приложение закрыто** - нужна Cloud Function

## Быстрое решение

### Вариант 1: Развернуть Cloud Function (рекомендуется)

Следуйте инструкциям в `DEPLOY_FUNCTIONS.md`

### Вариант 2: Проверить, что уведомления создаются

1. Создайте тестовый заказ
2. Измените его статус
3. Проверьте Firestore → `notifications` - должна появиться запись
4. Если запись есть - система работает, нужна только Cloud Function

### Вариант 3: Тестирование уведомлений в браузере

Когда приложение открыто, уведомления должны показываться через `onMessage` даже без Cloud Functions. Проверьте:
- Откройте приложение в двух вкладках (как клиент и как музыкант)
- Создайте заказ в одной вкладке
- Проверьте, появилось ли уведомление в другой вкладке

## Частые проблемы

### Проблема: "Уведомления не создаются в Firestore"

**Решение:**
- Проверьте правила Firestore для коллекции `notifications`
- Проверьте консоль на наличие ошибок
- Убедитесь, что пользователь авторизован

### Проблема: "Токен не сохраняется"

**Решение:**
- Проверьте правила Firestore для `userFCMTokens`
- Убедитесь, что пользователь разрешил уведомления
- Проверьте консоль на ошибки

### Проблема: "Cloud Function не отправляет уведомления"

**Решение:**
- Проверьте логи функции
- Убедитесь, что функция развернута
- Проверьте, что у получателя есть токен в `userFCMTokens`
