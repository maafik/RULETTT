# 🔍 Диагностика: Уведомления не приходят

## ✅ Что работает (по вашим логам)

- ✅ Разрешение на уведомления получено
- ✅ Service Worker зарегистрирован
- ✅ FCM токен получен и сохранен
- ✅ Слушатели настроены

## ❓ Почему уведомления не приходят на другой аккаунт?

### Шаг 1: Проверьте, развернуты ли Cloud Functions

**Проверка:**
```bash
cd functions
firebase functions:list
```

**Если функций нет:**
```bash
cd functions
npm install
firebase deploy --only functions
```

**Или проверьте в Firebase Console:**
1. Firebase Console → Functions
2. Должна быть функция `sendNotification`
3. Статус должен быть "Развернута"

### Шаг 2: Проверьте, создаются ли уведомления в Firestore

**В Firebase Console:**
1. Firestore Database → Коллекция `notifications`
2. Проверьте, появляются ли новые документы при создании/изменении заказа

**Что должно быть в документе:**
```json
{
  "targetUserUid": "UID_ПОЛУЧАТЕЛЯ",
  "orderId": "ID_ЗАКАЗА",
  "title": "Новый заказ",
  "body": "Текст уведомления",
  "status": "created",
  "read": false,
  "createdAt": "Timestamp"
}
```

**Если уведомления не создаются:**
- Проверьте консоль браузера на ошибки
- Проверьте правила Firestore для коллекции `notifications`
- Проверьте, что `targetUserUid` указан правильно

### Шаг 3: Проверьте, есть ли токен у получателя

**В Firebase Console:**
1. Firestore Database → Коллекция `userFCMTokens`
2. Найдите документ с UID получателя (второго аккаунта)
3. Проверьте, что поле `token` заполнено

**Если токена нет:**
- Получатель должен авторизоваться в приложении
- Разрешить уведомления
- Токен должен сохраниться автоматически

**Проверка через Firebase Console:**
1. Firestore Database → `userFCMTokens`
2. Найдите документ с UID получателя
3. Проверьте поле `token`

**Или проверьте в логах приложения получателя:**
- При загрузке должны быть логи с токеном
- Или проверьте DevTools → Application → Storage → IndexedDB

### Шаг 4: Проверьте логи Cloud Functions

**В Firebase Console:**
1. Functions → Logs
2. Найдите функцию `sendNotification`
3. Проверьте логи на наличие ошибок

**Что искать в логах:**
- ✅ `📬 Новое уведомление создано` - функция сработала
- ✅ `✅ Токен найден для пользователя` - токен найден
- ✅ `✅ Уведомление успешно отправлено` - уведомление отправлено
- ❌ `⚠️ Токен не найден для пользователя` - токен не найден
- ❌ `❌ Ошибка при отправке уведомления` - ошибка отправки

**Или через CLI:**
```bash
firebase functions:log --only sendNotification
```

### Шаг 5: Проверьте правильность targetUserUid

**Проблема:** Уведомление создается с неправильным `targetUserUid`.

**Проверка:**
1. Откройте уведомление в Firestore
2. Проверьте поле `targetUserUid`
3. Сравните с UID получателя в `userFCMTokens`

**Как получить UID получателя:**
- В консоли браузера получателя: `auth.currentUser.uid`
- Или в Firebase Console → Authentication → Users

### Шаг 6: Проверьте, работает ли Cloud Function

**Тест через Firebase Console:**
1. Создайте тестовое уведомление в Firestore:
   - Коллекция: `notifications`
   - Документ: новый
   - Поля:
     ```json
     {
       "targetUserUid": "UID_ПОЛУЧАТЕЛЯ",
       "orderId": "test",
       "title": "Тест",
       "body": "Тестовое уведомление",
       "status": "test",
       "read": false,
       "createdAt": "Timestamp.now()"
     }
     ```
2. Проверьте логи Cloud Functions
3. Должно появиться уведомление

## 🔧 Частые проблемы и решения

### Проблема 1: Cloud Functions не развернуты

**Симптомы:**
- Уведомления создаются в Firestore
- Но не отправляются
- В логах нет записей от Cloud Function

**Решение:**
```bash
cd functions
npm install
firebase deploy --only functions
```

### Проблема 2: Токен получателя не найден

**Симптомы:**
- В логах: `⚠️ Токен не найден для пользователя`
- Уведомление создается, но не отправляется

**Решение:**
1. Убедитесь, что получатель авторизован
2. Убедитесь, что получатель разрешил уведомления
3. Проверьте, что токен сохранен в `userFCMTokens/{uid}`
4. Попросите получателя перезагрузить страницу

### Проблема 3: Неправильный targetUserUid

**Симптомы:**
- Уведомление создается с неправильным UID
- Токен не найден для этого UID

**Решение:**
1. Проверьте функцию `getMusicianUidByName()` - правильно ли она работает
2. Проверьте, что `customerUid` или `musicianUid` указаны правильно
3. Добавьте логирование для отладки

### Проблема 4: Cloud Function не срабатывает

**Симптомы:**
- Уведомление создается
- Но Cloud Function не запускается
- Нет логов в Functions

**Решение:**
1. Проверьте, что функция развернута
2. Проверьте триггер: `functions.firestore.document('notifications/{notificationId}').onCreate`
3. Проверьте, что документ создается правильно

### Проблема 5: Уведомление отправлено, но не отображается

**Симптомы:**
- В логах: `✅ Уведомление успешно отправлено`
- Но уведомление не появляется

**Решение:**
1. Проверьте, что получатель разрешил уведомления
2. Проверьте, что браузер получателя не блокирует уведомления
3. Проверьте, что Service Worker работает на устройстве получателя
4. Проверьте, что приложение получателя открыто (для onMessage)

## 🧪 Тестирование

### Тест 1: Проверка создания уведомления

**В консоли браузера (отправитель):**

⚠️ **Важно:** В консоли браузера нельзя использовать алиасы `@/`. Используйте один из способов ниже:

**Способ 1: Через Firebase Console (рекомендуется)**
1. Откройте Firebase Console → Firestore Database
2. Создайте документ в коллекции `notifications`:
   ```json
   {
     "targetUserUid": "UID_ПОЛУЧАТЕЛЯ",
     "orderId": "test-order",
     "title": "Тест",
     "body": "Тестовое уведомление",
     "status": "test",
     "read": false,
     "createdAt": "Timestamp.now()"
   }
   ```
3. Cloud Function должна автоматически отправить уведомление

**Способ 2: Через код в приложении**
Добавьте временную кнопку в приложении для тестирования:
```typescript
// В компоненте
const testNotification = async () => {
  const { sendOrderNotification } = await import('@/lib/notifications');
  await sendOrderNotification(
    'UID_ПОЛУЧАТЕЛЯ',
    'test-order',
    'Тест',
    'Тестовое уведомление',
    'test'
  );
};
```

**Проверьте:**
1. Firestore → `notifications` → должен появиться документ
2. Functions → Logs → должна сработать функция
3. У получателя должно появиться уведомление

### Тест 2: Проверка токена получателя

**В консоли браузера (получатель):**
