# 🚀 Настройка Run Configuration в Android Studio

## 📱 Что такое Run Configuration?

Run Configuration определяет, как запускать приложение:
- На каком устройстве/эмуляторе
- Какой build variant использовать (debug/release)
- Какие опции запуска

## ✅ Автоматическая настройка

Android Studio обычно **автоматически создает** Run Configuration при первом открытии проекта.

### Проверка наличия конфигурации:

1. **Откройте Android Studio**
2. **Посмотрите на панель инструментов** (вверху)
3. **Должен быть выпадающий список** с названием типа "app" или "MusicBooking"

Если конфигурация есть - можно сразу запускать! ▶️

## 🔧 Создание Run Configuration вручную

Если конфигурации нет:

### Способ 1: Через меню

1. **Run → Edit Configurations...**
2. **Нажмите "+" (плюс)** в левом верхнем углу
3. **Выберите "Android App"**
4. **Заполните:**
   - **Name:** `app` (или любое имя)
   - **Module:** выберите `app` из списка
   - **Launch:** `Default Activity`
5. **Нажмите OK**

### Способ 2: Через панель инструментов

1. **Нажмите на выпадающий список** рядом с кнопкой Run (▶️)
2. **Выберите "Edit Configurations..."**
3. **Следуйте инструкциям выше**

## 🎯 Настройка конфигурации

### Основные параметры:

1. **Name:** Имя конфигурации (например, "app")
2. **Module:** `app` (основной модуль)
3. **Launch:** 
   - `Default Activity` - запуск главной активности
   - `Specified Activity` - указать конкретную активность
4. **Target:** 
   - `USB Device` - реальное устройство
   - `Emulator` - эмулятор
   - `Open Select Deployment Target Dialog` - выбор при запуске

### Build Variant:

- **Debug** - для разработки (по умолчанию)
- **Release** - для публикации

## 📱 Запуск приложения

### На реальном устройстве:

1. **Подключите Android устройство** через USB
2. **Включите USB отладку:**
   - Настройки → О телефоне → Нажмите 7 раз на "Номер сборки"
   - Настройки → Для разработчиков → USB отладка (включить)
3. **В Android Studio:**
   - Выберите устройство в выпадающем списке (рядом с Run)
   - Нажмите **Run (▶️)** или **Shift+F10**

### На эмуляторе:

1. **Создайте виртуальное устройство (AVD):**
   - Tools → Device Manager
   - Create Device → выберите устройство
   - Выберите системный образ (например, Android 14)
   - Finish
2. **Запустите эмулятор:**
   - Device Manager → нажмите ▶️ на устройстве
3. **В Android Studio:**
   - Выберите эмулятор в выпадающем списке
   - Нажмите **Run (▶️)**

## 🔍 Проверка конфигурации

### Если конфигурация не работает:

1. **Проверьте, что модуль `app` выбран:**
   - Run → Edit Configurations
   - Убедитесь, что Module = `app`

2. **Проверьте AndroidManifest.xml:**
   - Должна быть активность с `MAIN` и `LAUNCHER` (уже есть ✅)

3. **Синхронизируйте проект:**
   - File → Sync Project with Gradle Files

## ⚡ Быстрый запуск

После настройки конфигурации:

1. **Выберите устройство/эмулятор** в выпадающем списке
2. **Нажмите Run (▶️)** или **Shift+F10**
3. **Или нажмите зеленую кнопку** рядом с выпадающим списком

## 🐛 Частые проблемы

### "No target device found"

**Решение:**
- Подключите устройство через USB
- Или запустите эмулятор
- Или создайте новый AVD

### "Module 'app' not found"

**Решение:**
- File → Sync Project with Gradle Files
- Убедитесь, что открыли папку `android`, а не корневую

### "Default Activity not found"

**Решение:**
- Проверьте AndroidManifest.xml
- Убедитесь, что есть активность с `MAIN` и `LAUNCHER` (уже есть ✅)

## 📋 Стандартная конфигурация

Для вашего проекта стандартная конфигурация:

```
Name: app
Module: app
Launch: Default Activity
Target: Open Select Deployment Target Dialog
Build Variant: debug
```

Эта конфигурация должна создаваться автоматически при открытии проекта.

Просто выберите устройство и нажмите Run! ▶️
