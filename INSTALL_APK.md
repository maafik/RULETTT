# 📱 Как установить APK на телефон

## ⚠️ Проблема: APK не найден или не устанавливается

Если при нажатии на APK ничего не происходит, это может быть по нескольким причинам:

## 1️⃣ Проверьте, что APK собран

### В Android Studio:

1. **Откройте Android Studio** (проект должен быть открыт)

2. **Синхронизируйте Gradle:**
   - Нажмите кнопку "Sync Project with Gradle Files" (слон с синхронизацией) вверху
   - Или: File → Sync Project with Gradle Files
   - Дождитесь завершения синхронизации

3. **Соберите APK:**
   - Меню: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
   - Дождитесь сообщения "APK(s) generated successfully"

4. **Найдите APK:**
   - После сборки появится уведомление внизу справа
   - Нажмите "locate" в уведомлении
   - Или найдите вручную: `android/app/build/outputs/apk/debug/app-debug.apk`

## 2️⃣ Если APK найден, но не устанавливается

### На телефоне Android:

1. **Включите установку из неизвестных источников:**
   - Настройки → Безопасность → Неизвестные источники (включить)
   - Или при установке Android спросит разрешение - нажмите "Разрешить"

2. **Для Android 8.0+:**
   - При установке APK Android спросит разрешение
   - Нажмите "Настройки" → Включите "Разрешить из этого источника"
   - Вернитесь и установите APK

3. **Проверьте версию Android:**
   - APK собран для Android 6.0+ (minSdk 23)
   - Если телефон старее, нужно изменить minSdkVersion

## 3️⃣ Способы установки APK

### Способ 1: Через USB (самый простой)

1. Подключите телефон к компьютеру по USB
2. Скопируйте APK файл на телефон (в любую папку)
3. На телефоне откройте файловый менеджер
4. Найдите APK файл и нажмите на него
5. Нажмите "Установить"

### Способ 2: Через ADB (для разработчиков)

1. Включите USB-отладку на телефоне:
   - Настройки → О телефоне → Нажмите 7 раз на "Номер сборки"
   - Настройки → Для разработчиков → USB-отладка (включить)

2. Подключите телефон по USB

3. Выполните команду:
   ```bash
   adb install android/app/build/outputs/apk/debug/app-debug.apk
   ```

### Способ 3: Через облачное хранилище

1. Загрузите APK в Google Drive / Dropbox / OneDrive
2. Откройте на телефоне через приложение облачного хранилища
3. Скачайте и установите APK

### Способ 4: Через QR-код

1. Загрузите APK на веб-сервер или используйте сервис для обмена файлами
2. Создайте QR-код со ссылкой на APK
3. Отсканируйте QR-код на телефоне
4. Скачайте и установите

## 4️⃣ Проверка APK файла

### Убедитесь, что APK валидный:

1. **Размер файла:**
   - APK должен быть больше 1-2 МБ
   - Если меньше - сборка не завершена

2. **Расширение:**
   - Должно быть `.apk`, а не `.apk.zip` или другое

3. **Права доступа:**
   - Убедитесь, что файл не заблокирован Windows

## 5️⃣ Если сборка не работает

### Проверьте в Android Studio:

1. **Ошибки синхронизации:**
   - View → Tool Windows → Build
   - Проверьте, есть ли ошибки

2. **Версия Java:**
   - File → Project Structure → SDK Location
   - Убедитесь, что используется JDK Android Studio (не Java 24)

3. **Попробуйте через терминал Android Studio:**
   - View → Tool Windows → Terminal
   - Выполните:
     ```bash
     cd android
     .\gradlew.bat assembleDebug
     ```

## ✅ Быстрая проверка

1. Откройте Android Studio
2. Build → Build Bundle(s) / APK(s) → Build APK(s)
3. Дождитесь "APK(s) generated successfully"
4. Нажмите "locate" в уведомлении
5. Скопируйте APK на телефон
6. Установите на телефоне

## 🔍 Где найти APK

После успешной сборки APK будет здесь:
```
android/app/build/outputs/apk/debug/app-debug.apk
```

Если файла нет - сборка не завершилась успешно. Проверьте ошибки в Android Studio.
