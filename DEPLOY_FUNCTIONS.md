# Развертывание Cloud Functions для уведомлений

## Проблема

Уведомления создаются в Firestore, но не отправляются как push-уведомления, потому что нет Cloud Function для их отправки.

## Решение

Нужно развернуть Cloud Function, которая будет автоматически отправлять push-уведомления при создании записи в коллекции `notifications`.

## Шаги развертывания

### 1. Установите Firebase CLI (если еще не установлен)

```bash
npm install -g firebase-tools
```

### 2. Войдите в Firebase

```bash
firebase login
```

### 3. Инициализируйте Functions (если еще не инициализированы)

```bash
firebase init functions
```

Выберите:
- JavaScript (или TypeScript, если предпочитаете)
- Установить зависимости? Да

### 4. Установите зависимости

```bash
cd functions
npm install
cd ..
```

### 5. Разверните функции

```bash
firebase deploy --only functions
```

Или только функцию отправки уведомлений:

```bash
firebase deploy --only functions:sendNotification
```

## Проверка работы

### 1. Проверьте логи

```bash
firebase functions:log
```

### 2. Проверьте в Firebase Console

1. Откройте Firebase Console → Functions
2. Убедитесь, что функция `sendNotification` развернута
3. Проверьте логи выполнения

### 3. Протестируйте

1. Создайте тестовый заказ
2. Измените его статус
3. Проверьте, что в Firestore создалась запись в `notifications`
4. Проверьте логи функции - должно быть сообщение об отправке
5. Проверьте, пришло ли уведомление

## Структура файлов

```
project-root/
├── functions/
│   ├── index.js          # Cloud Functions
│   └── package.json     # Зависимости
└── firestore.rules      # Правила Firestore
```

## Альтернатива: Тестирование без развертывания

Можно протестировать локально с помощью эмуляторов:

```bash
firebase emulators:start
```

## Важно

- После развертывания функции уведомления будут отправляться автоматически
- Убедитесь, что у пользователей есть сохраненные FCM токены в `userFCMTokens`
- Проверьте, что правила Firestore позволяют создавать уведомления

## Troubleshooting

### Функция не срабатывает

1. Проверьте логи: `firebase functions:log`
2. Убедитесь, что функция развернута: Firebase Console → Functions
3. Проверьте, что уведомления создаются в Firestore

### Уведомления не приходят

1. Проверьте, что у пользователя есть токен в `userFCMTokens`
2. Проверьте, что пользователь разрешил уведомления в браузере
3. Проверьте логи функции на наличие ошибок

### Ошибка прав доступа

Убедитесь, что правила Firestore позволяют:
- Создавать уведомления (любому авторизованному)
- Читать токены (только владельцу)
