# 💳 Настройка биллинга Firebase для Phone Authentication

## ⚠️ Важно!

**Phone Authentication (отправка SMS) требует включенного биллинга в Firebase.**

## 🔧 Как включить биллинг:

### 1. Откройте Firebase Console
- Перейдите на [Firebase Console](https://console.firebase.google.com/)
- Выберите ваш проект

### 2. Включите биллинг
1. Нажмите на **шестеренку** (⚙️) рядом с "Project Overview"
2. Выберите **Usage and billing**
3. Нажмите **Upgrade** или **Manage billing account**
4. Следуйте инструкциям для добавления способа оплаты

### 3. Настройте Phone Authentication
1. Перейдите в **Authentication** → **Sign-in method**
2. Найдите **Phone** в списке
3. Нажмите **Enable**
4. Сохраните настройки

## 💰 Стоимость:

- **Бесплатный план (Spark):** 
  - ❌ Phone Authentication **НЕ доступен** без биллинга
  - ✅ Остальные функции Firebase работают бесплатно

- **Платный план (Blaze - Pay as you go):**
  - ✅ Phone Authentication доступен
  - 💵 Стоимость SMS: ~$0.06 за SMS (зависит от страны)
  - 💵 Первые $0 бесплатно каждый месяц

## 🧪 Альтернатива для разработки (БЕЗ БИЛЛИНГА И БЕЗ КАРТЫ):

### ✅ Использование тестовых номеров - РЕКОМЕНДУЕТСЯ!

**Firebase позволяет использовать тестовые номера БЕЗ привязки карты!**

Это идеальное решение для разработки:

1. Firebase Console → **Authentication** → **Sign-in method** → **Phone**
2. Нажмите **Enable** (это можно сделать без биллинга!)
3. Прокрутите вниз до **Phone numbers for testing**
4. Нажмите **Add phone number**
5. Добавьте тестовые номера:
   - **Номер:** `+79991234567` (любой формат +7XXXXXXXXXX)
   - **Код:** `123456` (любой 6-значный код)
6. Нажмите **Save**

**Преимущества:**
- ✅ Работает БЕЗ биллинга
- ✅ БЕЗ привязки карты
- ✅ Не тратятся деньги
- ✅ Мгновенная проверка (не нужно ждать SMS)
- ✅ Идеально для разработки и тестирования
- ✅ Можно добавить несколько тестовых номеров

**Ограничения:**
- ⚠️ Работает только с добавленными тестовыми номерами
- ⚠️ Для продакшена (реальные пользователи) нужен реальный биллинг с картой

## 📋 Пошаговая инструкция для тестовых номеров:

1. **Откройте Firebase Console:**
   ```
   https://console.firebase.google.com/project/ваш-проект/authentication/providers
   ```

2. **Включите Phone Authentication:**
   - Найдите "Phone" в списке провайдеров
   - Нажмите "Enable"
   - Сохраните

3. **Добавьте тестовые номера:**
   - Прокрутите вниз до "Phone numbers for testing"
   - Нажмите "Add phone number"
   - Введите номер (например: `+79991234567`)
   - Введите тестовый код (например: `123456`)
   - Сохраните

4. **Используйте в приложении:**
   - Введите тестовый номер в форму входа
   - При запросе кода введите тестовый код (например: `123456`)
   - Вход будет выполнен без реальной SMS!

## 🚀 Для продакшена:

Когда будете готовы к продакшену (реальные пользователи):

1. **Включите биллинг** (см. инструкцию выше)
2. **Привяжите кредитную карту** (обязательно для реальных SMS)
3. **Удалите тестовые номера** (или оставьте для тестирования)
4. **Настройте мониторинг** использования SMS в Firebase Console

**Важно:** Для продакшена карта обязательна, так как Firebase взимает плату за каждую отправленную SMS (~$0.06 за SMS).

### 🎯 Для разработки прямо сейчас (БЕЗ КАРТЫ):

1. **Откройте Firebase Console:**

   - Найдите "Phone" → Нажмите "Enable"
   - **НЕ нужно включать биллинг!**

   - Нажмите "Add phone number"

   - Код: `123456`
   - Сохраните

4. **Используйте в приложении:**
   - Введите `+79991234567` в форму
   - Введите код `123456`
   - Готово! ✅

**Карта НЕ нужна для разработки!**

### 💳 Для продакшена (с картой):

1. Включите биллинг
2. Привяжите кредитную карту
3. Настройте мониторинг расходов
4. Используйте реальные номера
